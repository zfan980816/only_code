# 性能基准（Performance Benchmarks）

可复现基准：`src-tauri/tests/bench.rs` 在临时目录生成 10,000 个真实代码结构的文件（TS/TSX/Python/JS/Java/Rust/Go/JSON/MD/CSS，含中文注释），调用与应用完全相同的代码路径计时。

运行：

```bash
cd src-tauri
cargo test --release --test bench -- --ignored --nocapture
```

## 结果（10,000 文件仓库，Windows，release 构建）

2026-11-12，Windows 11，x64，NVMe SSD：

| 操作 | 耗时 | 说明 |
|------|------|------|
| 后台索引（全量） | 7.4s | 76,000 符号 / 10,000 文件；**异步进行，UI 打开即可用** |
| 打开文件树（根目录） | **2.5ms** | 懒加载，仅展开当前层 |
| 全局搜索（命中 46 文件） | **12.9ms** | 流式返回 |
| 全局搜索（无命中，全量扫描） | 1.9s | 最坏情况：扫完全部 10k 文件 |
| 快速打开文件（Ctrl+P） | 520ms | 全表模糊匹配 |
| 打开单个文件 | **27ms** | 含安全路径校验 |

## 结论

UI 关键路径（文件树、搜索、打开文件）均为毫秒级；全量索引在后台异步进行，不阻塞阅读。“10,000+ 文件仓库打开不阻塞 UI”的目标达成。

机器与环境不同结果会有差异，欢迎用上述命令在自己机器上复现。
